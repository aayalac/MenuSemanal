# Menú Semanal
---
## Contexto:
Con necesidad de administrar semanalmente las comidas dentro del hogar y optimizar tiempos, se generó esta pequeña app con tecnología Razor para aleatoriamente sugerir un plan de los días de la semana.

## Utilidades:
Permite sugerir y editar cada una de las comidas de los 7 días de la semana para tener dinamismo sobre lo que se quiere trazar durante el plan semanal, esto permite ser dinámico y cambiante en la interacción de las necesidades del usuario sobre sus gustos y disponibilidad de cada plato listado.

# Contexto
---
Se requiere implementar una aplicación sencilla para mostrar un menú semanal de lunes a domingo a través de 3 secciones:
- Desayuno
- Almuerzo
- Cena 

Se debe mostrar una grilla con cada uno de los días de la semana y cada una de las 3 secciones de comidas por día.
en cada casilla se debe generar aleatoriamente uno de los elementos de cada día de acuerdo a las siguientes secciones, así mismo estas casillas puedes ser editables dentro de la misma:
